# 🚀 Web SSH Manager

Un gestore di connessioni SSH leggero, moderno e sicuro, racchiuso in un container Docker. Gestisci i tuoi server e accedi al terminale direttamente dal browser tramite un'interfaccia pulita e veloce.

---

## 🛠️ Requisiti di Sistema
Assicurati di avere installato sul tuo computer:
* **Docker**
* **Docker Compose**

---

## 📦 Installazione Rapida

Puoi configurare e avviare l'applicazione in pochi secondi utilizzando lo script di setup automatizzato.

1. **Scarica lo script di installazione** direttamente nella tua cartella home (o nella directory desiderata):
   ```bash
   curl -O [https://raw.githubusercontent.com/TUO-USERNAME/NOME-REPO/main/setup.sh](https://raw.githubusercontent.com/TUO-USERNAME/NOME-REPO/main/setup.sh)
