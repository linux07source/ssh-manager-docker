## 🛠️ Requisiti di Sistema
Assicurati di avere installato sul tuo computer:
* **Docker**
* **Docker Compose**

---

## 📦 Installazione Rapida

Puoi configurare e avviare l'applicazione in pochi secondi utilizzando lo script di setup automatizzato.

1. **Scarica lo script di installazione** direttamente nella tua cartella home (o nella directory desiderata):
   ```bash
   git clone https://github.com/linux07source/ssh-manager-docker.git
   ```
2. **entra dentro alla directory**
 ```bash
   cd ssh-manager-docker
```

4. **Rendi eseguibile lo script e avvialo**
 ```bash
   chmod +x setup.sh && ./setup.sh
```
5. **Rendi eseguibile lo script per gli altri OS e avvialo**
    ```bash
   chmod +x setup_other_os.sh && ./setup_other_os.sh
   ```

7. **Accedi alla pagina**

  ```bash
http://localhost:8080

 ```
